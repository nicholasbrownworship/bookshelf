Sync between devices

Real-time sync uses Firebase (free tier is plenty for two people's libraries). It takes about five minutes to set up once, then both of you will see the same shelf update live. Full steps are in the README — short version below.

1. Go to console.firebase.google.com and create a free project.
2. In the project, open Build → Authentication, click "Get started," and enable the Email/Password sign-in method.
3. Open Build → Firestore Database, click "Create database," and start it in test mode (we'll tighten the rules below).
4. In Firestore's Rules tab, paste:
allow read, write: if request.auth != null; 5. Back in Project settings (gear icon) → General → "Your apps," add a Web app, and copy the firebaseConfig object it gives you into the box on the Connect tab.
6. Pick any household ID (just a shared word) and create an account. Do the same "Sign in" (not "Create account") on your wife's device with the same household ID.
