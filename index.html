Bulk add by ISBN

Each one is looked up and added automatically as "Want to read," owner "Shared." Edit any of them afterward. This can take a little while for a long list — one request at a time, to stay polite to the lookup service.

Import from Goodreads / StoryGraph

Goodreads: My Books → Import and Export (left sidebar, under Tools) → Export Library → download the CSV.
StoryGraph: Settings → Manage Your Account → Export StoryGraph Library.
Ratings, shelves (as tags), read/want/reading status, and dates all come straight from the file — no lookups needed for those. Format (physical/ebook/audiobook) is guessed from the "Binding" column and can be off for a few titles; worth a glance after importing.

Display settings

Physical books show cover art only — QR codes only appear for ebooks/audiobooks that have a store link saved.
